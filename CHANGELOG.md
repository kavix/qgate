# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- GitHub repository open-source standards: Issue templates, PR template, CI workflow, Contributing guide, Code of Conduct, and Security policy.
- Initial crypto-agile policy evaluator for admission control.
- Algorithm-agnostic Signer/Verifier interface scaffold.
- Webhook server scaffold for Kubernetes validating admission.
- CLI scaffold for `keygen`, `sign`, and `verify`.

### Changed
- Project branding and module renamed from `pqc-gate` / `pqcgate` to `qgate`.
